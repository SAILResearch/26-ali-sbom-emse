Abstract

A Software Bill of Materials (SBOM) documents software components and their dependencies. Its adoption and utility depend on the tools that generate, analyze, and manage it. We compare tools supporting the two leading formats, SPDX and CycloneDX: use cases for 108 open-source and 62 proprietary tools; community health across 145 CycloneDX and 456 SPDX repository-format observations covering 573 distinct GitHub repositories; and 26,853 format-specific issue-report observations created since 2018, of which 26,772 received LLM-assisted category assignments. Finally, we compare the top 250 adopter projects per format. CycloneDX tools and their adopting projects show higher activity on several community-health metrics, while SPDX has more sampled OSS tool repositories. These findings describe tools listed in the official tool centers, their identifiable GitHub repositories and contributing forks, within our collection window.

📈
Regulatory Inflection Point

Closed CycloneDX issue counts begin to exceed SPDX counts around the 2021 US executive order. This temporal association does not establish that the order caused the shift. The category analysis covers 26,772 observations (14,763 CycloneDX; 12,009 SPDX), using an LLM-assisted approach calibrated on 379 manually checked issue reports. CycloneDX has significantly lower mean resolution times in seven of 14 categories after Bonferroni correction, with negligible to small effects.

RQ4

Adopter Project Profiles

How is the health of GitHub projects that use SBOM tools distributed?

💡
Key Insight

In this sample, projects with higher commit counts tend to use tools supporting View, Diff, and Import. Projects in the second commit quartile more often use tools supporting Analyze, Edit, and Merge. CycloneDX adopter projects have higher age-normalized community-health metrics, with effect sizes ranging from small to large. These associations do not establish that format choice causes higher activity.

Top-250 Adopter Project Comparison

Median counts normalized by repository age, per 10,000 days, for the top 250 projects per format; PRs are closed PRs

Searches found 2,426 distinct repositories: 307 SPDX-only, 1,087 CycloneDX-only, and 1,032 using both. The comparison selects the top 250 projects from each single-format group. Search patterns cover 11 SPDX and 50 CycloneDX tools and primarily capture Build-oriented invocations. In a validation sample, 81 of 87 retrievable entries (93.1%) were confirmed Build invocations; this does not measure adoption of other use cases or establish Build prevalence outside the search frame.
